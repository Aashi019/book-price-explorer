Book Price Explorer and Data Analysis

About the Project
This is a beginner-friendly web scraping project built with Python. It collects book information from Books to Scrape and analyzes the data.

Features
- Scrapes book titles, prices, availability, and star ratings.
- Collects data from five website pages.
- Stores the collected information in a Pandas DataFrame.
- Checks for missing values and duplicate rows.
- Finds the cheapest and most expensive books.
- Creates charts to analyze book prices and ratings.
- Exports the collected data to a CSV file.

Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas
- Matplotlib
- Jupyter Notebook

How to Run
1. Install Python.
2. Install the required libraries using `pip install -r requirements.txt`.
3. Open `book_price_explorer.ipynb` in JupyterLab.
4. Run the notebook cells in order.

Data Source
Practice website: https://books.toscrape.com/

This project is for learning and educational purposes.
